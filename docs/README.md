# InvestSeek docs

What each document in this folder covers. Start with the project [README](../README.md) ([中文](../README.zh-CN.md)).

| Document | What it covers | 内容 |
|---|---|---|
| [design-system.md](design-system.md) | The terminal design system: tokens for both themes and the three price conventions, type roles, color rules, the column-flow layout, panel codes, every UI primitive and the accessibility rules. | 设计系统：两套主题和三种涨跌配色的设计令牌、文字角色、配色规则、列式布局、面板代码、基础组件和无障碍规则。 |
| [signal-model.md](signal-model.md) | Specification of quant model v4: data, factors, composite and readings, the per-stock backtest with its permutation test, the risk forecast and the evidence so far. | 量化模型 v4 的规格：数据、因子、综合分与读数、带置换检验的个股回测、风险预测和目前的证据（含中文摘要）。 |
| [evaluation.md](evaluation.md) | Generated by `npm run evaluate`: the pinned universe evaluation of the technical score (rank IC with Newey-West t, readings split into timing and selection, the holdout decade, the hindsight gap). | 由 `npm run evaluate` 生成：技术评分在固定区间上的全股票池评估（秩 IC 与 Newey-West t、择时与选股分解、留出样本、后见之明缺口）。 |
| [factor-research.md](factor-research.md) | Generated by `npm run research`: the pre-registered factor study with Holm and Benjamini-Hochberg adjustment, statistical power, the hindsight gap and the calibration of the risk forecast. | 由 `npm run research` 生成：事先登记的因子研究（Holm 与 BH 校正）、统计功效、后见之明缺口和风险预测的校准。 |
| [deployment.md](deployment.md) | Self-hosting with Docker and Caddy, Node.js without Docker, Vercel and its caveats, private site mode, every setting, startup checks, health endpoints, logs and security headers. | 部署指南：Docker 与 Caddy、不用 Docker 的 Node.js 部署、Vercel 及其注意事项、私有模式、全部配置项、启动检查、健康检查、日志和安全响应头。 |
| [testing.md](testing.md) | End-to-end and accessibility tests; the README's [Testing](../README.md#testing) section has the summary. | 端到端与无障碍测试；摘要见 README 的[测试](../README.zh-CN.md#测试)一节。 |
| [roadmap-v0.3.md](roadmap-v0.3.md) | The v0.3 plan from the eight-lens audit, with what shipped in 0.3.0, what stays deferred and what remains (in Chinese). | v0.3 路线图：八个角度审查后的计划，以及 0.3.0 已交付、暂缓和待完成的部分。 |
| [optimization-plan.md](optimization-plan.md) | Historical: the audit of the 0.1 app (122 verified findings) and how the 0.2.0 rewrite implemented it. Superseded by the v0.3 roadmap; kept for reference. | 历史文档：对 0.1 版的审查（122 条已核实的问题）及 0.2.0 重写中的实施情况，已由 v0.3 路线图取代，留作参考。 |
| [screenshots/](screenshots/) | Images for the READMEs (regenerated after the end-to-end suite lands). | README 使用的截图（端到端测试合并后重新生成）。 |

`evaluation.md` and `factor-research.md` are generated: change the scripts or the pinned settings in `scripts/evaluation.config.json` and re-run them instead of editing the files. `npx tsx scripts/check-links.ts` checks every relative link and image in these documents and in the root Markdown files.

Elsewhere in the repository: [CHANGELOG.md](../CHANGELOG.md), [CONTRIBUTING.md](../CONTRIBUTING.md) and [SECURITY.md](../SECURITY.md).
