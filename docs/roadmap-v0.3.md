> 制定日期：2026-11-07 ｜ 基线：commit cde5f91（v0.2.0）

> 依据：8 个审查代理分别从模型方法、因子实测、数据可用性、功能板块、用户体验、视觉设计、AI 助手和工程运维 8 个角度独立通读代码，并用真实行情做了实验；其中报告的 8 条缺陷都由另一个代理独立复核，全部成立。

## 一、四个核心判断

1. **收益预测不可靠，风险预测可靠。** 用 2016–2026 年、78 只大盘股、7 个事先登记的因子（12-1 动量、短期反转、52 周高点、低波动、低 Beta、现有技术评分、等权组合）做检验，经过多重检验校正（Holm、BH）后没有一个能预测收益；看似显著的结果来自 Beta 暴露和"用今天的成分股回看过去"的幸存者偏差。相反，过去 63 日波动率与未来波动率的截面秩相关为 0.72，过去一年 Beta 与未来 Beta 为 0.77，且每个子区间都成立。所以 v0.3 的量化重心从"预测涨跌"转向"预测风险"：预期波动区间、波动分位、Beta、回撤概率，并公布实测校准覆盖率。
2. **现有"历史表现"表本身有统计问题。** 评估窗口锚定在运行当天，换一天开始，10 日结论就会从"无可靠关系"变成"反向"；"极弱读数之后 +2.17%"里有 58% 是大盘择时，不是选股，2016–2026 全样本上这一项其实是 -0.70%。需要改为：固定区间、全部交易日的 IC 加 Newey-West t 值、择时与选股分解、按日期分块的 bootstrap 区间、2014–2024 留出样本。
3. **产品把市场放在了投资者前面。** 首页最后才出现自选，持仓从不在首页出现；个股页不知道你是否持有；财报日、除息日埋在关键数据最底部；所有个人数据只在浏览器里，却没有导出备份。
4. **视觉上的"AI 味"来自几个系统性选择。** 红绿同时表示当日涨跌、月度走势和模型判断；热力图色阶几乎分不出 +2.8% 和 +11%；79% 的文字是等宽字体；页面网格把每行拉到最高面板，留下 159–720px 的空白；浏览器标签页还是 Vercel 的三角图标。

## 二、v0.3 要做的事

### 量化与模型

- 修正评估方法：固定区间配置、全部交易日 IC + Newey-West t、网格相位敏感性、择时与选股分解、分块 bootstrap 区间、事件集中度、2014–2024 留出样本，去掉"最佳标签"一行。
- 新增因子研究脚本 `scripts/research-factors.ts`：事先登记的因子、Holm 与 BH 校正、行业中性与 Beta 调整后的 IC、剔除事后赢家、统计功效、成分股相对 RSP 的幸存者偏差缺口。结果写入 `lib/factor-research.json` 和 `docs/factor-research.md`。
- 风险预测：个股预期 10 日波动区间（20 日与 252 日方差等权混合，历史覆盖率约 72% / 94%）、波动分位、Beta、各波动五分位"一个月内回撤 10% 以上"的历史频率。
- 模型 v4：把"波动率状态"移出方向性评分（它衡量的是风险，不是方向），评分改称"短期相对强弱"，不再调权重。
- 个股回测加循环置换检验，区分不了随机择时的数字一律灰显。
- 因子画像：各因子在股票池里的分位，旁边写明该因子在本股票池里实测的 IC，不用红绿色。
- `/lab` 因子实验室页面：展示上述全部证据和统计功效说明。

### 新板块

- **组合分析 PORT/CORR**：按市值的行业与资产类别暴露、各持仓对组合风险的贡献、相关性矩阵、"如果一直持有当前持仓"相对 SPY 的走势、回撤、VaR、有效持仓数。
- **财经日历 EVTS**：持仓与自选的财报（盘前/盘后、是否预估）、除息日与金额、FOMC/CPI/非农；个股页加财报面板（一致预期、修正趋势、历史超预期）和分析师面板。
- **筛选器 EQS 与全市场发现 MOST**：78 只股票和 26 只 ETF 的估值、股息、动量、波动、Beta 筛选，预设与保存方案；全市场涨跌幅榜、成交活跃榜和雅虎创意清单。
- **图表工作台 GP**：1 日与 5 日分时、对比 SPY 或行业 ETF、成本线与目标价/止损线、分红标记、MA200、布林带、RSI 副图、对数坐标。
- **投资笔记 NOTE 与本地提醒 ALRT**：论点、目标价、止损位、复盘日期；价格、涨跌幅、财报临近等提醒，回到页面时补报错过的触发。
- **数据自主**：导出与恢复备份、券商 CSV 导入持仓、粘贴持仓、导出 CSV。
- **全球市场与利率 WEI/GC**：亚欧美主要指数、汇率、商品，美国国债收益率曲线（财政部数据）和市场宽度。
- **功能代码与帮助**：`NVDA GP`、`EQS`、`PORT` 这类终端式命令，`?` 快捷键面板，`/help` 页面。

### 体验与视觉

- 首页"我的今日"：组合今日盈亏和主要贡献者、本周事件；个股页显示你的持仓并在图上画出成本线；列表显示盘前盘后价格。
- 修复：中文公司名搜索、旧报价冒充实时、热力图键盘跳转 87 次、密码框 id 重复、输入框对比度。
- 视觉：红绿只用于价格与盈亏；热力图分档色阶加图例与悬停卡片；数字改用 IBM Plex Sans 等宽数字；面板标题层级；列式布局消除空白；新图标与字标；三个签名细节（面板功能代码、置信区间须线、交易时段条）。

### AI 助手

- 对话能看到持仓，提示词不再自相矛盾，并明确告知持仓会发送给 DeepSeek。
- 加入财报一致预期、超预期历史、预期修正和分析师动作；新增"为什么在涨跌"，按大盘、行业、同行和公司新闻逐层归因并标注引用；组合扫描预先算好贡献、排名和风险数据，避免模型把关系说错。
- 笔记和对话本地保存、推荐问题、复制与重试、按资产类型（ETF、加密货币等）调整笔记结构、相同上下文的笔记服务端缓存。

### 工程

- 端到端测试：雅虎数据回放模式与模拟 LLM，CI 不再访问雅虎或 DeepSeek；Playwright 冒烟测试与 axe 无障碍检查。
- Docker 镜像与 compose、启动时环境变量校验、带上游健康状态的就绪检查、结构化日志、私有站点模式与 nonce CSP、PWA 清单与图标、社交卡片、雅虎接口每日巡检、GitHub 社区文件。

## 三、暂不做的事（及原因）

| 事项 | 原因 |
|---|---|
| 历史成分股（point-in-time）股票池与 SEC EDGAR 基本面 | 能从根上消除幸存者偏差、检验价值与质量因子，但需要约 700 只股票 20 年数据和离线管线，工作量大，列为下一阶段 |
| 交易流水与真实收益率（TWR/XIRR） | 需要大量录入，应在 CSV 导入稳定后再做 |
| 标普 500 全量筛选器 | 需要维护成分股名单，先用 78 只股票与全市场发现覆盖 |
| 多实例共享限流（Upstash Redis） | 只在多实例部署时需要，个人使用推荐 Docker 单进程 |
| 结构化 AI 流、逐条数字溯源、工具调用 | 改动面大，先完成数据补全和引用 |
| 离线 Service Worker | 容易缓存旧代码和旧数据，先做可安装的 PWA |

## 四、执行方式

1. 数据层地基（已完成，commit 62e6e1e）：历史序列、筛选器、因子画像、财经日历、全市场发现、扩展行情字段、旧报价标记、中文名称表、风险与因子库。
2. 第一批并行（已完成，合并提交 52dc4c2、6687e67、f235327）：设计系统、量化研究与评估修正、工程运维。
3. 第二批并行（已完成，合并提交 5881679 至 ba7c4ca）：外壳与导航、组合、日历与财报、筛选器、量化界面、个股页与图表、笔记与提醒、数据自主、AI、首页与全球市场。每个工作包在独立的 git worktree 中开发并自测，文件归属事先划定，避免冲突。
4. 合并后（进行中）：独立多代理复审与修复已在各工作包合并前完成，文档已完成；端到端与无障碍测试在独立分支上开发，截图在它合并后重新生成。
